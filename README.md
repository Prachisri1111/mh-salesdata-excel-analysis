# mh-salesdata-excel-analysis
Sales data analysis using Microsoft Excel and basic Excel functions. This project demonstrates the use of formulas, mathematical and logical functions, text and date functions, lookup functions, and data processing to organize, analyze, and derive meaningful insights from sales records.

# MH Sales Data Analysis

# Overview

This project focuses on sales data analysis using Microsoft Excel and basic Excel functions.
It demonstrates how formulas and functions can be applied to organize, process, and analyze sales records to derive meaningful insights from data.

# Objectives

- Understand and organize sales data.
- Apply basic Excel formulas and functions.
- Perform mathematical calculations and conditional data processing.
- Analyze customer, product, pricing, and delivery information.
- Use text and date functions to manipulate data.
- Improve accuracy and efficiency when working with spreadsheets.

# Dataset

Dataset Name: `MH_SalesData.xlsx`

The dataset contains sales-related information, including order details, customer information, product categories, quantities, prices, discounts, and delivery dates.

# Key Concepts Covered

- Data Sorting and Filtering:Organizing records and displaying relevant data based on specific criteria.
- Logical Functions: Using IF, AND, and OR to evaluate conditions.
- Array Formulas: Applying array-based calculations and classifications.
- Mathematical Calculations: Calculating sales amounts and final amounts after discounts.
- Text Functions: Using LEFT, UPPER, and text concatenation to manipulate text.
- Date Functions: Using TODAY to work with the current date.
- Conditional Data Processing: Applying conditions to categorize records and evaluate eligibility.
- Sales Calculations and Discount Analysis: Working with quantities, prices, discounts, and sales amounts.
- Customer Code Generation: Combining text from different fields to create codes.
- Priority Order Identification: Identifying orders based on specified conditions.

# Tools and Technologies

- Microsoft Excel
- Excel Formulas and Functions
- Spreadsheet Data Processing

# Learning Outcomes

- Develop practical skills in Microsoft Excel.
- Understand how to apply formulas and functions to sales data.
- Perform calculations and conditional checks efficiently.
- Manipulate text and date values using Excel functions.
- Organize and interpret structured datasets.
- Strengthen problem-solving and data-handling skills.
